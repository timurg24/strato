# Strato Defines

A list of defines that set some limits. Change these to increase limits.

## Strato

- `STRATO_MAX_ENGINES` - Maximum number of engines per aircraft (Default is 8)
- `STRATO_PHYS_HZ` - Simulation speed in Hz (Default is 120hz)
- `STRATO_TERRAIN_QUALITY` - Changes the terrain texture size (increasing this may not increase terrain quality as it is capped by the API) (Default is 256)

## Wrangler

- `MAX_LIGHT_COUNT` - Maximum light count per scene/render call
